LEGO Builder

Detailed User Guide – 3D Virtual Brick Building Tool

🖱️ Mouse Controls – Regular Computer (Desktop / Laptop)

The builder uses standard OrbitControls — very similar to 3D viewers in games, CAD, and design tools.

  • Left mouse button drag → orbit / rotate the camera around the model
  • Right mouse button drag → pan / move the view left/right/up/down
  • Mouse wheel scroll → zoom in / zoom out smoothly
  • Click a brick → select it (yellow border if enabled)
  • Shift + Click → add/remove bricks from multi-selection
  • Click + drag on selected brick(s) → move them freely in the X/Z plane (auto-snaps to grid on release)
  • Click empty space → deselect everything
Tip: Hold right mouse and drag to quickly recenter your view if you get lost in space.

📱 Using on iPad / Tablets (Touch Gestures)

Works well in Safari/Chrome on iPad — touch support is built-in, but gestures can feel slightly less precise than mouse.

  • One finger drag → orbit / rotate view
  • Two-finger drag → pan the view
  • Two-finger pinch/spread → zoom
  • Tap brick → select
  • Tap & hold + drag on selected brick → move in X/Z (snaps on release)
iPad tips: Use landscape mode + Add to Home Screen for cleaner full-screen experience.
Nudge buttons (X/Y/Z ±) are often more reliable than long drags.
Gestures may get "sticky" after long sessions — lift fingers and touch again.
Performance good on recent iPads; very large models (>500 bricks) may slow down.

🧱 Building Large Models – Hundreds of Bricks

Your LEGO models can easily reach **hundreds of bricks** (500–1000+ is realistic) — the system is designed to handle reasonably large scenes without crashing.

  • Snapping and movement remain fast even with many pieces
  • Save/load works fine — files stay small (usually <10–50 KB even for big builds)
  • Performance depends on device:
    • Modern desktop/laptop → smooth with 1000+ bricks
    • Recent iPad (M1/M2/M4) → good up to ~600–800 bricks
    • Older devices or phones → slow above ~200–300 bricks
For very large models: hide borders (uncheck box) to improve rendering speed, and save incremental versions often.

💾 Save & Load – Editable Text Format

Save creates a file called lego-scene.json — this is a plain **text file** (JSON format).

  • You can open it in any text editor: Notepad, TextEdit, VS Code, Sublime Text, etc.
  • It contains:
    • Every brick (type, size, exact position)
    • Your current camera position, rotation, target & zoom
  • You can hand-edit positions, add bricks manually, or fix mistakes if you're comfortable with JSON
  • Load → pick any previously saved .json file to resume exactly where you left off (including viewpoint)
Pro tip: Make copies with names like model-v1.json, model-v2.json → gives you basic version history since there's no undo.

🔧 Other Controls

  • Delete Selected → removes highlighted bricks
  • Show borders checkbox → toggle wireframes (helps see selection & edges)
  • Hide Controls (top-right) → clean canvas view; tap again to show UI
  • Y± buttons → move up/down one plate at a time (perfect stacking)
