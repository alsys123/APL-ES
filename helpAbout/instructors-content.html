Instructor Guide

🛠️ Building Exams for Students

Instructors can generate two types of student-facing exams using the Exam Builder:

  • Student‑Only Exam – Answers are hidden, grading tools are disabled.
  • Student‑Only + Learning Notes – Answers remain hidden, but students can view explanatory notes after answering.

These modes ensure students can study and practice without having access to the full answer key. The “Full” version of the exam is reserved for instructors, grading or self-study.

🎲 Randomized Answer Options

Every time a student begins a new session, the answer options for each question are automatically scrambled. This means:

  • Each student sees a unique ordering of answer choices
  • Two students taking the same exam will not have identical option layouts
  • Exported progress files are unique per student

This randomization helps reduce answer‑sharing and encourages genuine understanding.

📦 Student Export Files

When a student exports their progress, the resulting ZIP file contains:

  • Their unique option order for every question
  • Their selected answers
  • The number of attempts they made on each question
  • Section-by-section progress

Because each student’s exam is randomized, every export file is different—even if two students answer the same questions correctly.

🚫 Hidden Tools in Student‑Only Mode

In Student‑Only exams, certain tools are intentionally disabled:

  • Toggle Answer – Hidden, since answers are not available
  • Grade Exam – Disabled or non-functional
  • Auto‑Check – Not available unless using the Learning Notes version
  • Full Exam Report - This is a hidden report in both student and full mode. In full mode this can be unlocked by pressing Bottom Page and Up Page, three (3) times.

This ensures students cannot reveal the correct answers directly from the interface.

🧪 Grading a Student’s Exam

To grade a student’s work:

  1. Open the Full version of the exam (instructor mode)
  2. Click ⬆ Import
  3. Select the student’s exported ZIP file
  4. The system will reconstruct the student’s randomized exam
  5. Click 📊 Grade Exam to view results

The instructor version contains the full answer key, allowing accurate grading even when the student’s options were scrambled.

🤖 Future AI‑Generated Exams

The APL‑ES structure is designed to support future AI‑assisted exam creation. Emerging systems such as ChatGPT, Grok, and Copilot may eventually be able to generate:

  • Complete exam question banks
  • Learning notes and explanations
  • Section and part structures
  • Adaptive difficulty paths

Because APL‑ES uses a consistent format—300 questions across 6 sections and 30 parts—it provides a strong framework for AI‑generated learning systems.

📚 A Structured Learning System

The APL‑ES exam format is intentionally designed to reinforce memory and understanding:

  • 6 Sections provide broad topic coverage
  • 10 Parts per section break content into manageable chunks
  • 5 Questions per part encourage focused learning

This structure supports both instructor‑led training and self‑guided study, making APL‑ES a flexible platform for aviation education and beyond.
